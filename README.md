## 🛠️ How To Build

- Build w/ CMake.

```
cmake ..
cmake --build .
```

- Run any test in `./build/*`.

```
./build/minimal
./build/lines
./build/frame
./build/button
./build/hello_world
./build/puzzle
./build/two048
./build/minesweeper
./build/entry
./build/external_class
```
